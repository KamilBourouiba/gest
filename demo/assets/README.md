# Mannequin asset

`mannequin.glb` is the **Xbot** rigged character from the [Three.js examples](https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf) (Mixamo-style humanoid, ~2.8 MB).

Used by:

- `demo/breakthrough_lab.html` (Three.js + CCD IK)
- `unity/GestDemo/Models/mannequin.glb` (Humanoid IK in Unity)

The model is bundled for offline demos on Vercel and in the Unity `testgest` project. Retargeting is driven by `.gest` hand/gaze channels, not by semantic animation labels.
